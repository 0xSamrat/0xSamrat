## 👋 Hey, I'm Samrat

I'm a builder at heart. I got into blockchain not because it was trendy — but because I genuinely wanted to understand how money, trust, and systems could work without middlemen.

That curiosity led me down a rabbit hole: from writing my first smart contract to designing full-blown trading platforms that handle thousands of concurrent operations. Along the way, I picked up Golang for building fast, concurrent backend systems, Solidity for on-chain logic, TypeScript for protocol tooling, and a deep appreciation for how distributed systems and EVM chains actually work under the hood.

Today, I specialize in **building things that sit at the intersection of finance and technology** — DeFi protocols, perpetual trading engines, cross-chain systems, and the infrastructure that makes them reliable at scale. I've worked with teams shipping real products, won hackathons building everything from decentralized swaps to cross-chain DAO governance, and even secured grants to bring my own ideas to life.

When I'm not writing code, you'll find me exploring new protocol designs, stress-testing systems to their breaking point, or growing communities around the projects I believe in.

**What I bring to the table:**

- 🏗️ System design & distributed architecture for high-throughput platforms
- ⛓️ Deep experience building on EVM chains, DeFi protocols & financial systems
- 🚀 End-to-end engineering — from smart contracts to off-chain trade engines
- 🛠️ Golang, Solidity, TypeScript — choosing the right tool for each layer
- 🧪 Rigorous testing culture — from unit tests to adversarial protocol simulations

📍 Bengaluru, India  ·  📬 samrat.mukherjee2022@gmail.com

## 🔥 What I've Built

### ⚡ Perpetual Trading Engine — Defipe.io
`Aug 2023 – Apr 2025` · Remote

> Designed and shipped an off-chain perpetual trading system from scratch — order book, position lifecycle, margin, liquidation, and funding rate mechanics. Built the core trade engine in **Golang** handling **1,000+ monthly trades** with concurrent order matching and leverage control. Integrated CoinGecko pricing, engineered low-latency **WebSocket state propagation** delivering **sub-50ms updates** to **500+ active users**. Reduced long/short position imbalance by **35%** through enhanced funding rate algorithms. Applied liquidation logic preventing 100% undercollateralized positions across **10K+ simulated trades**.

---

### 🔗 Cross-Chain Protocol Infrastructure — AtumLabs
`Jul 2025 – Oct 2025` · Remote

> Built cross-chain **Solidity escrow and fulfillment contracts** with strong asset safety guarantees across multichain transactions. Defined protocol invariants for asset locking, release, and replay protection. Created **TypeScript SDKs** with circuit breakers and rate limiting, boosting downstream API reliability by **45%**. Migrated legacy shell-based workflows to **Golang automated API testing**, doubling framework reliability. Built CLI tools simulating **1,000+ concurrent transactions** for stress-testing protocol performance.

---

### 🎨 NFT Marketplace on Polygon — TechExactly
`Jan 2022 – Oct 2022` · Kolkata, India

> Designed EVM-compatible Solidity contracts for an NFT marketplace securing **100+ transactions**. Integrated **ERC-2612 permit-based approvals**, reducing gas costs by **~40%**. Achieved **95%+ test coverage** with Hardhat. Automated Polygon (Mumbai) deployments via scripted pipelines, reducing deployment errors by **60%**. Built a **React + Redux** frontend prototype, reducing UI-related transaction retries by **30%**.
